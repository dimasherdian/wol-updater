# Wars of Liberty Updater (Unofficial)

This is an unofficial, community-made updater for Wars of Liberty (WoL), a fan-made modification for Age of Empires III.

**Disclaimer**: This is NOT an official Wars of Liberty project. It is not affiliated with, endorsed by, or owned by the Wars of Liberty development team.

## Requirements
- Java 17

## Build
This project uses the Maven Wrapper. Do not use a globally installed Maven.

```powershell
.\mvnw.cmd clean package
```
